# 项目范围与十月改进

Arachne 是 MoonBit 正则行为契约与兼容性测试工具。项目九月已经存在，十月工作是在既有契约执行和双后端适配基础上增加机器可读报告、测试夹具和工具链兼容修订。

## 九月已有能力

九月末已有契约与黄金预期、官方正则适配器、re-mbt ASCII Perl 适配器、文本差异报告、整段跨度检查、有限 Unicode 边界夹具及双引擎演示。这些能力不重复列为十月新增。

## 十月改进

- 增加类型化 JSON v1 报告及可执行示例、结果快照。
- 递归排序 JSON 对象键，确保同一报告具有稳定序列化结果。
- 扩展迁移夹具，覆盖共享 ASCII 行为、语法差异、适配器输入边界、捕获和跨度回归。
- 更新工具链兼容性并将测试扩展至 30 项；主分支 CI 在 default、JS、native 三个目标通过。

可在仓库提交历史中查看每项实际代码变化。提交数量或文档修订本身不作为新增功能或赛事资格证明。主分支 CI 记录：[GitHub Actions](https://github.com/wallll-wal6/arachne/actions/runs/38509773560)。

## 范围限制

本仓库不包含正则解析器或匹配器实现；这些能力来自 `moonbitlang/regexp` 与 `walkzzz/re-mbt` 公开依赖。适配器只归一化已选用例中的结果，不证明所有输入等价。re-mbt 适配器限 ASCII。Unicode 类别表标注 Unicode 17.0，但原始输入的独立来源记录尚待核实，因此仅保留现有有限夹具，不扩大覆盖声明。类别资格和成果认定以赛事审核为准。
