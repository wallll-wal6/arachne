# 项目范围与十月改进

Arachne 是 MoonBit 正则行为契约与兼容性测试工具。项目九月已经存在；针对十月初审指出的核心工程深度不足，新增了一个独立实现、范围受限的 MoonBit ASCII 参考正则引擎，同时继续维护原有兼容性工具。

## 九月已有能力

九月末已有契约与黄金预期、官方正则适配器、re-mbt ASCII Perl 适配器、文本差异报告、整段跨度检查、有限 Unicode 边界夹具及双引擎演示。这些能力不重复列为十月新增。

## 十月改进

- 增加类型化 JSON v1 报告及可执行示例、结果快照。
- 递归排序 JSON 对象键，确保同一报告具有稳定序列化结果。
- 扩展迁移夹具，覆盖共享 ASCII 行为、语法差异、适配器输入边界、捕获和跨度回归。
- 更新工具链兼容性并将测试扩展至 36 项；新参考引擎已通过本地严格检查与测试，跨目标结果以本次 CI 为准。
- 新增自有递归下降解析器、Thompson NFA 编译器和去重状态集执行器，将其接入现有 `EngineAdapter` 契约，可与官方正则后端共享夹具并报告实际差异。
- 为参考引擎补充子集语法、左侧起点优先/最长结果语义、ASCII 与捕获边界、语法拒绝和长近似失败回归用例；本地严格检查和测试覆盖扩展后的套件。

可在仓库提交历史中查看每项实际代码变化。提交数量或文档修订本身不作为新增功能或赛事资格证明。主分支 CI 记录：[GitHub Actions](https://github.com/wallll-wal6/arachne/actions/runs/38509773560)。

## 范围限制

自有参考引擎仅支持有限 ASCII 语法，不实现捕获值、回引用、环视、计数重复或完整 Unicode，并限制模式与输入长度；它不替代通用正则库。两个外部后端仍通过公开依赖提供。适配器和有限夹具不证明所有输入等价。re-mbt 适配器也限 ASCII。Unicode 类别表标注 Unicode 17.0，但原始输入的独立来源记录尚待核实，因此仅保留现有有限夹具，不扩大覆盖声明。类别资格和成果认定以赛事审核为准。
