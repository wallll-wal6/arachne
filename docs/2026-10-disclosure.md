## 申报人与团队

项目负责人及唯一团队成员为韦安良，团队只有本人；这一事实由负责人在项目对话中明确说明。`moonbitlang/regexp` 与 `walkzzz/re-mbt` 是公开依赖，其维护者不是 Arachne 团队成员。公开 API 接入不表示共同开发或共同维护；本次申报不列入任何上游贡献成果。

## 九月驳回与十月回应

负责人在对话中提供的九月驳回通知截图能确认的理由是：旧申报把 Arachne 描述为自研正则引擎，仓库实际是基于公开引擎的行为契约测试项目，项目边界没有披露。十月申报据此统一为正则行为契约 / 兼容性测试工具，明确本仓库与公开引擎各自的实现职责，不将依赖的解析和匹配能力计为本项目实现。

负责人此前提供的九月 Markdown 申报书包含自研引擎、解析器、匹配算法与性能宣称；这些宣称不适用于当前仓库，不作为十月能力申报。尚未取得的是九月最后实际提交的完整在线申报表及最终附件版本确认。驳回截图能确认上述理由，但不能还原所有申报字段，也不能据此确认其他驳回理由。

## 实现与公开依赖

| 项目 | 事实与依据 |
| --- | --- |
| 定位 | MoonBit 正则行为契约 / 兼容性测试工具；契约、适配、比较及报告由本仓库实现，解析与匹配由公开依赖提供 |
| 契约与报告 | `contract.mbt` 定义契约及比较；`json_report.mbt` 提供 JSON v1 |
| 官方依赖 | `moon.mod` 声明 `moonbitlang/regexp@0.3.5`；`moon.pkg` 导入其公开包；适配器调用 `compile` / `execute` |
| re-mbt 依赖 | `moon.mod` 声明 `walkzzz/re-mbt@0.1.0`；导入 `walkzzz/re-mbt/re`；适配器只调用 Perl 前端，主动限制为 ASCII 模式与输入 |
| 依赖归属 | 两套引擎作为独立依赖分发，本仓库未纳入其解析或匹配源码；依赖能力不计为本项目实现 |
| Unicode 数据 | 范围表标注为 Unicode 17.0；生成脚本读取外部 `UnicodeData.txt`；样例生成有数量上限，数据不用于执行匹配；原始输入版本与来源尚缺独立溯源记录 |
| 示例范围 | 四套件预期用例 / 后端 / 差异为 7/2/0、1/2/1、2/2/2、8/1/0；见[迁移示例](../examples/demo/README.md) |
| 限制 | 单次整段匹配、数字捕获文本和代码单元跨度；Unicode 示例仅官方后端；无全输入等价证明、超时、沙箱或性能保证 |
| 许可 | 本仓库 `LICENSE` 为 Apache-2.0；引擎和数据的独立许可见[第三方说明](../THIRD_PARTY_NOTICES.md) |
