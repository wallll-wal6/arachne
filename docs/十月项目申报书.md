## 项目简介

Arachne 将正则表达式的“模式、输入、预期结果”写成可重复执行的契约，在选定的正则后端上运行并报告行为差异，帮助 MoonBit 开发者检查依赖升级或替换对应用行为的影响。项目自身实现契约执行、适配、结果比较和报告；正则解析与匹配由公开依赖提供。

## 核心功能与技术路线

- 以 MoonBit 契约描述编译接受、匹配结果、匹配文本、整段跨度和数字捕获值，并对每个适配器复用已编译模式。
- 通过适配器接入 `moonbitlang/regexp` 和 `walkzzz/re-mbt` 的公开 API，生成文本与 JSON v1 差异报告；提供示例、黄金结果和回归测试。
- `re-mbt` Perl 适配器限于 ASCII 模式与输入；Unicode 边界夹具只覆盖有限回归样例，不代表跨引擎等价或完整 Unicode 覆盖。

## 预期使用场景

1. **请求编号回归：**对 `^req-([0-9]+)$` 与输入 `req-42` 固定匹配文本、捕获值 `42` 和跨度 `[0, 6)`，并验证 `req-` 不匹配；依赖行为漂移时报告具体用例。
2. **替换后端前比较语法：**以 `^([a-z])\1$` 检查 `aa`。当前两套适配器观测到官方引擎接受并匹配、re-mbt Perl 前端拒绝编译；报告呈现差异，迁移取舍由应用维护者决定。
3. **偏移回归：**对 `(a)` 在 `🦊a` 中匹配 `a`，断言 UTF-16 代码单元跨度 `[2, 3)`，用于发现适配器偏移换算错误。
