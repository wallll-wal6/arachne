## 项目简介

Arachne 把正则表达式的模式、输入和预期结果写成可重复运行的行为契约，用于比较不同 MoonBit 正则后端在编译、匹配文本、跨度和捕获值上的差异，帮助开发者评估依赖升级或替换带来的兼容性变化。

## 核心实现与使用方式

- 契约层复用已编译模式，执行匹配与非匹配、整段跨度及捕获组检查，并输出稳定文本报告和 JSON v1 报告。
- 本期新增 MoonBit 原生 ASCII 子集参考引擎：递归下降解析构建语法树，编译为 Thompson NFA，以去重状态集执行匹配，作为第三个可检查、可对照的后端。
- 参考引擎支持字面量、`.`、锚点、字符类与常用字符类转义、分组、选择及 `*` / `+` / `?`；采用最左起点、同一起点最长匹配。它不支持捕获、回引用、环视和完整 Unicode；模式及输入长度受限，不能替代通用正则库。
- 通过适配器对照自有参考引擎、`moonbitlang/regexp` 与 `walkzzz/re-mbt`。例如可检查回引用在不同后端上的编译差异，或用 Emoji 前缀用例验证 `StringView` UTF-16 跨度换算。有限夹具不代表所有模式等价。
