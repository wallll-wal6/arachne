## 定位与九月初审回应

依据仓库现有草案转述的定位与依赖边界问题，本次统一将项目申报为“MoonBit 正则行为契约与回归测试库”。“自研正则表达式引擎”的表述与当前代码不符，应予修正；Arachne 不实现正则解析或匹配算法。**[待确认：九月申报及初审原文，正式递交前逐项核对回应。]**

Arachne 的自有 MoonBit 代码负责契约用例、适配器调用、结果归一化、基线比较和稳定差异报告；解析与匹配由公开依赖 `moonbitlang/regexp@0.3.5`、`walkzzz/re-mbt@0.1.0` 提供。两者通过公开 API 接入，未在本仓库复制或修改其引擎实现；上游维护者不是 Arachne 团队成员，依赖使用不代表共同开发、维护或上游贡献。Unicode 17.0 范围表是另附许可的生成数据。详见[项目边界](positioning.md)与[第三方说明](../THIRD_PARTY_NOTICES.md)。

## 已有基础与项目价值

以九月 30 日提交 `2357942` 为代码基线，已有公共适配器接口、黄金预期校验、编译缓存、编译/执行/匹配文本/跨度/捕获组比较、Unicode 类别边界样例、两个真实后端适配器、文本报告、可运行示例和 CI 配置。它们帮助应用在升级或切换正则后端前发现行为变化，均列为已有成果，不重复计入十月新增工作。

本库仅报告已测输入的行为差异，不自动判定某个引擎有错，也不证明全输入等价。`re-mbt` 适配器仅支持 ASCII 模式和输入；Unicode 样例使用官方适配器。偏移量统一为 MoonBit `StringView` 代码单元，当前不提供执行超时或沙箱。
