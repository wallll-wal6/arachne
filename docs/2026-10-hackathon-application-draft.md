# Arachne｜十月项目申报正文

**项目名称与仓库：**Arachne — MoonBit 正则行为契约 / 兼容性测试工具。[GitHub 仓库](https://github.com/wallll-wal6/arachne)。

**项目简介：**把应用依赖的正则行为写成可重复执行的“模式、输入、预期结果”契约，在选定基线与候选引擎上运行，比较编译接受、是否匹配、匹配文本、整段跨度及捕获值，输出文本与 JSON 差异报告，帮助开发者评估依赖升级或替换的影响。

**MoonBit 方向及通用价值：**基础库 / 开发者工具，以 MoonBit 实现契约执行、适配、比较和报告。日志提取、请求校验及文本处理都依赖稳定的正则行为；调用者可复用同一套用例，通过适配器接入其他引擎或版本，并把报告纳入测试与 CI。

**痛点与现有方案差异：**只看引擎支持的语法或一次匹配成功，无法判断应用依赖的捕获值、偏移和拒绝行为是否改变。现有 `moonbitlang/regexp` 与 `walkzzz/re-mbt` 提供解析和匹配；Arachne 在其上提供共享契约、黄金预期、观测归一化及逐项差异，相比逐个后端手写断言，集中维护应用行为要求与比较规则。优势在可重复核对和定位差异，不以新增匹配算法或速度为目标。

**三个完整预期使用场景：**

1. **请求编号校验回归。**使用者：MoonBit 服务维护者。输入：模式 `^req-([0-9]+)$`，字符串 `req-42`、`req-`。操作：将前者的匹配文本、捕获 `42` 和跨度 `[0, 6)`，以及后者的不匹配写成契约，在两个内置适配器运行。预期结果：两者符合预期且无差异；以后依赖变更造成偏离时，报告定位到用例与后端。
2. **更换正则依赖前检查语法差异。**使用者：应用开发者。输入：模式 `^([a-z])\1$` 与字符串 `aa`。操作：以官方引擎为基线、re-mbt Perl 适配器为候选运行并查看双方结果。预期结果：官方引擎编译成功并匹配，候选拒绝编译，报告一项编译接受差异；开发者据此调整规则或决定是否迁移。
3. **Unicode 偏移回归。**使用者：文本处理库维护者。输入：模式 `(a)`、字符串 `🦊a`，预期文本及捕获均为 `a`，跨度 `[2, 3)`。操作：在官方适配器执行跨度契约，并用 Unicode 类别边界样例补充回归输入。预期结果：按 UTF-16 代码单元返回正确跨度；适配或升级后偏移出错会触发预期失败，便于发现字节、码点与代码单元混用。

**拟交付核心功能与技术路线：**围绕已具备基础实现的契约与可选黄金预期、基线 / 候选比较、两种真实后端适配器、文本与 JSON v1 报告、有数量上限的 Unicode 类别边界样例，以及可运行示例和回归测试完善交付。采用 MoonBit 类型化用例和观测模型；适配器调用公开引擎 API，统一为整段文本、零起点右端不含的跨度和数字捕获文本；每次运行按适配器复用同一模式的编译结果，按用例及适配器顺序保留结果。重用现有引擎，集中验证应用行为，是本项目的实现路径。

**范围边界：**只报告所选用例的行为，不证明全输入等价；当前返回一次整段匹配，不提供所有匹配、命名组映射或捕获组跨度。re-mbt 适配器只接受 ASCII 模式与输入，Unicode 示例仅使用官方引擎。类别数据用于生成测试输入；不实现解析器或匹配引擎，不提供超时、沙箱或性能保证。无差异仍须检查逐项失败结果，最终迁移决定由应用负责人作出。

**是否移植 / 参考项目及许可：**本项目为基于公开引擎的集成测试工具，不属于正则引擎移植；本仓库实现契约、适配、比较及报告，通过公开 API 依赖 [moonbitlang/regexp@0.3.5](https://github.com/moonbitlang/regexp.mbt)（Apache-2.0）和 [walkzzz/re-mbt@0.1.0](https://github.com/walkzzz/re-mbt)（LGPL-2.1-or-later，含链接例外）。两套引擎源码未纳入本仓库，依赖能力不计为本项目实现。Arachne 源码采用 Apache-2.0，Unicode 数据保留独立许可。

**AI 辅助披露：**项目目标与定位由负责人明确；AI 辅助源码、依赖与文档检查、修改及本申报材料整理。
